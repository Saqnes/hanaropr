## 내부 확인 전 단정하지 않는 정보

- 정확한 창립연도: 팀 현재 홈페이지는 1995, 서울대학교 2023 보도자료는 1999 등 공개 자료가 서로 다릅니다.
- 현재 활동 인원과 파트별 인원
- HARANG 페이로드 실제 분리 성공 여부
- HARANG 2의 세부 제원과 비행 결과
- 현재 모집 자격, 최소 활동 기간, 회비·재료비·원정 비용
- 현재 후원사와 로고 사용 권한
- 임원 연락처와 공식 기부 절차

## 콘텐츠 운영 원칙

1. 모든 고도·속도·연소시간은 `Target`과 `Result`를 구분합니다.
2. 프로젝트마다 기준일, 공개 출처, 콘텐츠 담당자를 기록합니다.
3. 실패는 숨기지 않고 확인된 사실과 배운 점만 씁니다.
4. 모집 일정·운영진·후원 절차는 배포 직전에 다시 확인합니다.
5. 사진은 팀 공식 홈페이지에서 제공된 자산만 사용하고, 인물·후원사 로고 공개 권한을 운영진이 최종 확인합니다.
